# SETUP INSTRUCTIONS - CODEBASE GENIUS
# Comprehensive Installation and Running Guide

## SYSTEM REQUIREMENTS

### Minimum Requirements:
- Python 3.8 or higher
- Git 2.0 or higher
- 4GB RAM (8GB recommended)
- 1GB free disk space
- Internet connection for repository cloning

### Supported Operating Systems:
- Linux (Ubuntu 18.04+, CentOS 7+)
- macOS 10.14+
- Windows 10/11

## INSTALLATION GUIDE

### Step 1: Clone Repository
```bash
git clone https://github.com/Kipng3n0/Codebase-Genius
cd Codebase-Genius
```

### Step 2: Create Virtual Environment
```bash
# Create virtual environment
python -m venv venv

# Activate virtual environment
# On Linux/macOS:
source venv/bin/activate

# On Windows:
venv\Scripts\activate

# Verify activation (should show venv path)
which python
```

### Step 3: Install Dependencies
```bash
# Upgrade pip first
pip install --upgrade pip

# Install required packages
pip install fastapi uvicorn streamlit requests gitpython

# Verify installation
pip list | grep -E "(fastapi|uvicorn|streamlit|requests|gitpython)"
```

### Step 4: Verify Installation
```bash
# Test Python imports
python -c "import fastapi, uvicorn, streamlit, requests, git; print('All dependencies installed successfully')"

# Check Git installation
git --version
```

## RUNNING THE APPLICATION

### Method 1: Using Two Terminals (Recommended)

#### Terminal 1 - Backend Server:
```bash
cd Codebase-Genius
source venv/bin/activate  # On Windows: venv\Scripts\activate
cd backend
python api_server.py
```

Expected output:
```
Starting Codebase Genius API...
API will be available at http://localhost:8000
API docs at http://localhost:8000/docs
INFO:     Started server process [XXXX]
INFO:     Waiting for application startup.
INFO:     Application startup complete.
INFO:     Uvicorn running on http://0.0.0.0:8000 (Press CTRL+C to quit)
```

#### Terminal 2 - Frontend Interface:
```bash
cd Codebase-Genius
source venv/bin/activate  # On Windows: venv\Scripts\activate
cd frontend
streamlit run app.py
```

Expected output:
```
  You can now view your Streamlit app in your browser.

  Local URL: http://localhost:8501
  Network URL: http://192.168.x.x:8501
```

### Method 2: Using Background Processes

#### Start Backend in Background:
```bash
cd backend
nohup python api_server.py > ../logs/backend.log 2>&1 &
echo $! > ../logs/backend.pid
```

#### Start Frontend in Background:
```bash
cd frontend
nohup streamlit run app.py > ../logs/frontend.log 2>&1 &
echo $! > ../logs/frontend.pid
```

#### Stop Background Processes:
```bash
# Stop backend
kill $(cat logs/backend.pid)

# Stop frontend
kill $(cat logs/frontend.pid)
```

## TROUBLESHOOTING

### Common Issues and Solutions:

#### 1. Port Already in Use
**Error**: `[Errno 98] address already in use`
**Solution**:
```bash
# Find process using port 8000
lsof -ti:8000

# Kill the process
kill -9 $(lsof -ti:8000)

# Or use different port
uvicorn api_server:app --port 8001
```

#### 2. Module Not Found
**Error**: `ModuleNotFoundError: No module named 'fastapi'`
**Solution**:
```bash
# Ensure virtual environment is activated
source venv/bin/activate

# Reinstall dependencies
pip install -r backend/requirements.txt
```

#### 3. Git Clone Fails
**Error**: `Failed to clone repository`
**Solutions**:
- Check internet connection
- Verify repository URL is correct
- Ensure repository is public
- Check Git installation: `git --version`

#### 4. Streamlit Not Starting
**Error**: `streamlit: command not found`
**Solution**:
```bash
# Ensure virtual environment is activated
source venv/bin/activate

# Install streamlit
pip install streamlit

# Verify installation
streamlit --version
```

#### 5. Permission Denied
**Error**: `Permission denied` when creating temp directories
**Solution**:
```bash
# Check temp directory permissions
ls -la /tmp

# Create custom temp directory
mkdir -p ~/codebase-genius-temp
export TMPDIR=~/codebase-genius-temp
```

### Configuration Files:

- `.gitignore`: Ignored files and directories
- `frontend/.streamlit/config.toml`: Streamlit configuration (optional)

## PERFORMANCE OPTIMIZATION

### For Large Repositories:
1. Increase timeout values in API calls
2. Use SSD storage for better I/O performance
3. Ensure sufficient RAM (8GB+ recommended)
4. Close unnecessary applications

### Caching:
- Analysis results are cached in memory
- Clear cache by restarting backend server
- Cache persists until server restart

## SECURITY CONSIDERATIONS

### Network Security:
- Backend runs on localhost:8000 (not exposed externally)
- Frontend runs on localhost:8501 (not exposed externally)
- No authentication required for local usage

### Repository Access:
- Only public repositories are supported
- No credentials stored or transmitted
- Temporary clones are automatically cleaned up
